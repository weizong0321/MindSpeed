# 电商智能导购助手（多模态 · 可核实属性版）

## 项目介绍

基于 **Qwen3.5-0.8B** 与 **MindSpeed-MM（昇腾 CANN）** 微调的电商导购模型。
支持「商品图片 + 文字需求」联合输入，读出图中**客观可判别的结构属性**并给出购买建议。

**核心设计取舍（有实测依据，不是拍脑袋）**

本项目系统评估了"图片能可靠支撑什么断言"，结论如下：

| 断言类型 | 跨标注者一致率 | 处理方式 |
|---|---|---|
| 颜色（"主色是X"） | 0.67–0.73（4B 与 30B 相同，**换更大模型无改善**） | **不断言** |
| 自由文本"列 3–5 个可见特征" | **0.133**（目标本身欠定） | **弃用** |
| **闭词表互斥属性**（鞋帮高度/开合方式/有无侧袋…） | **0.85–1.00** | **采用** |

因此本 Skill 采用「**模型只读属性 + 代码渲染文案**」的两段式结构：
模型只输出第一句属性陈述（48 token），其余文案由确定性模板生成。
这样既避免编造，也把"是否真看图"变成可精确评测的指标。

## 能力边界（请如实对外说明）

✅ **能做的**：图上客观结构属性的判别，例如
- 鞋类：开合方式（系带/魔术贴/一脚蹬/拉链）、鞋帮高度（低帮/中帮/高帮）、鞋头形状、鞋底类型
- 包类：背法（双肩/单肩/斜挎/手提）、开合方式、有无侧袋
- 手表：表带材质（金属/皮革/编织/橡胶）、表盘形状
- 钱包：开合方式、有无背带
- 电器：类型、装取方式、有无显示屏
- 首饰：类型、有无吊坠、链子粗细

❌ **不做的**：颜色、材质手感、尺码、价格、容量、耐用性、防滑等级
—— 这些图上无法可靠核实，回答中统一以"以商品页标注为准"兜底。

**实测精度**（78 张分层评测图）：
- 整张图的属性**全部答对**：**75.6%**（95% CI 65–84%）
- 对照·完全不看图、只答类别众数：**51.3%**（95% CI 40–62%）
- 净增益 +24 个百分点，两者置信区间不重叠

**覆盖范围**：11 / 21 个品类有经过验证的属性能力；其余品类只给品类与免责说明。
**已知失败项**：`appliance_large.type` 平衡准确率低于多数类基线（会把壁挂空调答成洗衣机）。

## 技术栈

| 项 | 值 |
|---|---|
| 训练框架 | MindSpeed-MM（FSDP2 后端） |
| 基础模型 | Qwen3.5-0.8B |
| 算力平台 | Ascend 910B2（单卡，HBM 64 GB） |
| CANN | 8.5.0 |
| torch_npu | 2.7.1 |
| 训练数据 | 570 张商品图 / 908 条问答 / 闭词表属性目标 |

## 目录结构

```
ecommerce_guide_skill/
├── SKILL.md                       # 本文件
├── skill.yaml                     # Skill 元信息
└── scripts/
    ├── run_chat.py                # 交互式入口（真正加载模型）
    ├── extract_and_render_model.py# 属性读取器（加载 / 生成 / 反解）
    ├── attr_spec.py               # 各品类闭词表属性定义
    ├── attr_render.py             # 属性值 ⇄ 自然短语双向映射
    └── render_answer.py           # 确定性答案渲染器
```

## 运行方式

```bash
cd ecommerce_guide_skill/scripts
python run_chat.py --model /path/to/qwen3_5_0.8B_sample8b_hf
```

交互说明：

| 输入 | 行为 |
|---|---|
| `图片路径\|你的需求` | 图文联合咨询（推荐） |
| `exit` | 退出 |

示例：

```
顾客：/data/images/bag_backpack/bag_backpack_002/001.jpg|这个包适合通勤吗
导购AI：图中看是一个双肩包，拉链、无侧袋。通勤时要装电脑、要轻便、能不能放水杯
        这些从图上判断不了，需要以商品页标注为准。
        （读出的属性：{"closure": "拉链", "side_pocket": "无"}）
```

## 环境变量提醒

训练/推理脚本使用的环境变量（由 `train_qwen35.sh` 设置）：
`NON_MEGATRON=true`、`MULTI_STREAM_MEMORY_REUSE`、`TASK_QUEUE_ENABLE`、
`PYTORCH_NPU_ALLOC_CONF=expandable_segments:True`。

> 注意：`source /workspace/mindspeed_env.sh` 会**切换工作目录**到 `/workspace/MindSpeed`，
> 脚本里依赖相对路径时务必**先 source 再 cd**。
